# MZ Cake Showcase — Editable Website Project

This is an editable HTML/CSS/JavaScript website project for Visual Studio Code (VS Code).

## Open and edit
1. Extract this ZIP.
2. Open Visual Studio Code.
3. Select **File → Open Folder** and choose `MZ_showcase_editable`.
4. Open `index.html` to edit the page. The CSS is currently inside the `<style>` section and JavaScript is inside the `<script>` section of this file.
5. To preview, open `index.html` in a browser, or use the VS Code **Live Server** extension and choose **Open with Live Server**.

## Product images
The HTML references these image files in the `assets` folder:
- `chocolate-can.png`
- `red-velvet-can.png`
- `strawberry-can.png`
- `cookies-cream-cake.png`

The uploaded ZIP did not contain those image files. Add the matching images with these exact filenames to `assets` so they appear on the page.
